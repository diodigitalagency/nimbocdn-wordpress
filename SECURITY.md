# Security policy

## Supported versions

The latest release is supported. Security fixes are released as a new version and offered at https://nimbocdn.net/install, on WordPress.org (once listed) and as a GitHub Release here.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Write to **hello@nimbocdn.net** with "Security" in the subject, or use [GitHub's private vulnerability reporting](https://github.com/diodigitalagency/nimbocdn-wordpress/security/advisories/new) on this repository. Include the plugin version, the steps to reproduce, and the impact you believe it has.

You will get an acknowledgement within 3 business days, and a fix or a clear status within 14 days for confirmed issues. We will credit you in the changelog unless you prefer otherwise.

## Scope

- This plugin (everything in this repository).
- The NimboCDN service it talks to: the control plane and the delivery edge. Reports about the service are welcome at the same address.

## What the plugin does with data

The plugin collects no personal data about site visitors. What it sends to the service, when, and why is disclosed in the **External services** section of [`readme.txt`](readme.txt), and in the privacy policy at https://nimbocdn.net/privacy.
